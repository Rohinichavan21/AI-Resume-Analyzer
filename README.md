# AI Resume Analyzer

An AI-powered Resume Analyzer built using Python and Streamlit.  
The system analyzes a resume against a given job description and provides skill matching, NLP-based similarity, and resume improvement suggestions.

## 🚀 Features

- 📄 Upload Resume in PDF format
- 🤖 AI/NLP-based Resume Analysis
- 🧠 Skill Extraction and Matching
- 📊 Resume Match Score
- 🔍 Matching and Missing Skills
- 💡 Resume Improvement Suggestions
- 🔐 Login System
- 🚪 Logout
- 📋 Analysis History
- 💾 Previous Analysis Records
- 📥 Downloadable PDF Report
- 🔄 Reset Analysis
- 🗄️ SQLite Database for Analysis History
- 🎨 User-friendly Streamlit Dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- PyPDF
- ReportLab
- SQLite
- NLP
- TF-IDF
- Cosine Similarity
